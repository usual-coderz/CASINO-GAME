How It Works

Our crash game uses a provably fair algorithm that ensures results cannot be manipulated by either the server or the player. Here's the exact process:

Step 1: Server generates a random 32-byte seed serverSeed = randomBytes(32) Step 2: Server publishes the SHA256 hash before the round serverSeedHash = SHA256(serverSeed) Step 3: Player provides or generates a client seed clientSeed = player-defined string Step 4: Crash point is calculated using HMAC-SHA256 hmac = HMAC-SHA256(serverSeed, clientSeed + ":" + nonce) h = first 13 hex chars of hmac (52 bits) e = 2^52 result = floor((100 * e - h) / (e - h)) / 100 crashPoint = max(1.00, result)

Properties:
• RTP = 99%, House Edge = 1%
• P(crash = 1.00x) ≈ 1% (instant bust)
• Memoryless distribution - past rounds don't affect future rounds
• Deterministic - same inputs always produce the same crash point
• Verifiable - you can reproduce the server's calculation independently
